# Retail Project SQL

Script en PostgreSQL con las tablas clientes, productos y ventas,
sus restricciones (PK, FK, CHECK) y una carga inicial de datos.

## Cómo ejecutarlo
1. Crear una base de datos llamada `retail_project`.
2. Abrir el Query Tool en pgAdmin o DBeaver, conectado a esa base.
3. Ejecutar `retail_project.sql` completo.
